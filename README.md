### 发生了什么
当时初一从市里转回乡镇，冬天比较冷，学校还没翻修，空气很干燥，我小学一直是好学生，所以没有谈过恋爱也没想过谈恋爱，我是在三楼的二班，在放学时先会在走廊排好队伍，这使得刚刚放学时两班学生会混在一起聊天，(她在我班有两个闺蜜会串插到我们班玩，后面认识后得知)，再次期间，我总感觉看到了一个面孔令我忍不住多看几眼，皮肤很白皙很漂亮，第二天，或者第一天？我在排队时她过来了并打听我是不是新转来的学生，我很羞涩感觉心跳快了许多，回答玩她话锋一转问我眼镜多少度，(或许当时她在准备配眼镜？)没等我回答，她用手拿下了我的眼镜并戴在她脸上(不知道为什么会突然拿，和戴上)，然后因为感觉到那种近距离的感受突然就感觉心跳停了半拍，或许这就是心动吧，然后我一直暗暗观察，但并未表现出明显的喜欢，我记得我经常去走廊，去上厕所为了多看到她几次，当时我是三人拼桌？好像是？旁边是胡和龚，偶然一次听见她在我们班有两个闺蜜中流出都姓名，我经常在两个同桌面前询问此人，说感觉长得还挺漂亮，并打听到与初二某人正在谈恋爱，所以一直在暗暗观察希望能多看几眼，等待那一个月左右结束(学期结束)，随后寒假没有见过她，以为以后我们并不会有交集……
